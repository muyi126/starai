# 漫剧来源、版本和局部恢复

## 使用方式

- 已有剧本：在漫剧输入区勾选“输入是已有剧本／原文”。后端用 `source_script` 原文校验模型返回的 `source_quote`，再直接切取原文，不采用模型重写的引用。
- 创意生成：来源绑定到本次生成的 `script`，界面标明“本次生成剧本”，不冒充用户原文。
- 每个分镜的 `source` 保存 UTF-8 字节边界、完整片段和 SHA-256；`verified` 仅表示原文定位正确，不保证镜头语义或画面一致性。
- 复刻画布保留实际请求的视频地址和运行签名，拒绝倒序、重叠的来源时间段。媒体内容的真实性仍需视觉模型或人工验收。
- 运行中可展开漫剧素材面板，查看已完成关键帧和视频。原有逐步确认／自动托管逻辑不变。

## 恢复与兼容

- 替换关键帧只失效相同分镜 ID 的视频；缺失 ID 时无法可靠关联，保守失效全部片段。旧素材保存在 `outputs.media_history`，界面可打开对比。
- 重试关键帧保留其他视频和独立配音，由 Worker 检查来源兼容性；合成失败继续复用已有片段。
- 媒体替换、节点重试以项目状态及旧 outputs 做条件更新，拒绝覆盖已变化的数据；运行中的项目仍不可替换素材。
- 新关键帧使用版本 2 签名，加入关联资产版本、视觉定义和画质。旧关键帧继续使用原签名算法，升级本身不触发付费重生成。
- 新视频签名补充时长、画质、音频策略和绑定资产。旧视频继续使用既有兼容性检查。
- 生成前归档已有图像／视频版本；历史链接依赖原有素材存储可用性，不等于永久备份。
