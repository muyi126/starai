# 画布角色与通用 Agent 工作流

两节点工作流采用默认专业角色，无需额外填写。复杂工作流为脚本、视频反推、资产拆解、分镜、关键帧、视频片段、配音、音乐、合成分别提供职责预设；每个节点可选择、修改或关闭角色。角色属于制作岗位，画面人物身份由上游参考与设定约束，不能混用。

对“优化”目录原文的调整：

- 分镜数量按动作、对白和时长决定，不机械按字数；允许空镜，解决“每镜必须有对白”的冲突。
- 分镜不重新设计服饰与外貌，但必须沿用已确认资产设定。
- 视频反推区分可见事实与估计，不强行推断精确焦段、光圈，不承诺相同参数能一比一复现。
- 资产角色保留人物、场景、道具分类与别名归并；商品已有 Logo、包装文字不作为水印删除，未知信息不猜写。
- 岗位角色提示不覆盖节点原有结构化输出协议，避免 JSON 和分隔符协议冲突。
- 配音正文与角色说明分离，不能把制作指令朗读进成品。合成节点使用确定性的素材检查与合成参数，角色文字不会被当成 FFmpeg 命令执行。

后台无限画布工作流管理可选择“提示词增强模型”；留空时依次采用工作流分析模型和通用 Agent 主聊天模型。增强调用沿用聊天计费与内容检查；用户在等待期间改写内容时，不覆盖新内容。

超过两个节点显示智能托管／逐步确认。逐步确认每次推进一个待执行节点；继续时复用已完成结果，编辑上游后下游失效。执行模式随画布保存、导出和恢复。

角色预设包含输入依据、制作方法、人物与商品一致性、交付要求和职责边界；对白编排与实际配音使用不同岗位。下游只接收上游产出与输入素材，不重复注入上游生成节点的旧任务指令。关闭角色后不附加该节点的角色提示词。配音风格控制取决于模型支持的参数，合成岗位说明不代表额外执行了视觉质检。

运行进度和阶段等临时状态不参与节点输入签名，保证逐步继续和保存恢复后能够复用结果。视频创作明确勾选“生成前确认分镜”时，智能托管同样会在生成媒体前暂停。

Agent 已确认方案创建真实无限画布：文生图、参考图生图、图片编辑、文生视频、图生视频、视频创作、爆款复刻、内容图文、语音或音乐分别选择对应模板，并复用画布执行器。执行器在 Agent 页面后台运行，不自动打开画布；分析和方案确认保留在聊天中，步骤确认、失败重试以及最终成品也直接在聊天中展示。参考图生图使用图片创作角色，图片编辑使用保留未修改部分的编辑角色。中间素材不作为成品发送。

纯文字文章、文案、脚本、歌词和提示词成品使用 `text` 计划，确认后进入画布文字工作流，采用聊天模型和写作角色生成完整正文。普通问答、解释和写作方法讨论继续使用聊天回复。视频和音频／音乐的逐步确认提供直接播放预览；最终媒体及文字正文都回传到 Agent，已完成文字也会提供给后续改写或媒体创作的上下文。

恢复 Agent 历史会加载原画布并恢复成品、进度或继续入口；聊天中的“查看工作流记录”和无限画布历史可查看同一份记录。旧 AI 漫剧项目仍可以查看，新提交的旧方案转入视频创作。运行仍由浏览器画布执行器编排；关闭 Agent 页面后，已提交媒体任务继续在服务端处理，后续节点可回到 Agent 历史中确认继续，无需打开画布。
